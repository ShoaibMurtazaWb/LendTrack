# @lendtrack/web

Next.js App Router app for LendTrack (UI + API routes under `src/app`).

## Develop

From the monorepo root:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploy from the **repository root** on Vercel (`npm run build`). See the root [README](../../README.md#deploy-on-vercel) for env vars and dashboard checklist.
